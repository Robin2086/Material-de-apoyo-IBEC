# Material-de-apoyo-IBEC
Material de apoyo necesario para seguir los ejemplos y ejercicios del escrito “Introducción a la Bioinformática con un Enfoque Clínico"

## Contenido
Archivos sin formato que contienen secuencias para realizar los ejercicios y ejemplos del Manual de Bioinformática con un Enfoque Clínico:
  * HSD17B1
  * blast_ejemplo
  * fragmento
  * secuencia_A
  * secuencia_B
  * secuencias_pax6
  * tcoffee_pax6

Archivos de salida para visualizar los resultados de ejercicios y ejemplos del Manual de Bioinformática con un Enfoque Clínico:
  * msa_pax6_mview.out
